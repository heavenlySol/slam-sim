How the simulation works

  • 2-D simulated LiDAR casts 120 rays per scan, up to 6 m; green lines show the latest scan.
  • Ray traversal updates free-space and occupied-cell log odds.
  • Wheel odometry is noisy; conservative scan-to-map matching applies only small, evidence-backed pose corrections to avoid drifting along featureless aisles.
  • When both side boundaries are visible, the rover steers toward the midpoint of their measured distances; a conservative one-wall fallback is used only for nearby side returns. Weak or open-space readings do not steer it.
  • It starts with a lawnmower sweep, then switches to frontier exploration (known-free cells bordering unknown space) and stops when no frontier is found or the step budget is reached.
  • The blue rover marker and red estimated trajectory update live during mapping; the final PNG retains the trajectory.

Research note: This is an educational 2-D SLAM simulator, not a validated production SLAM system. Compare the output with ground truth to measure its errors.

Rack route planner

First run Identify racks for the same map, then enter the displayed IDs (for example R01, R03, R02). The planner finds free approach cells beside each rack footprint, routes around occupied cells, and returns to the dock. Leave Rack IDs blank to visit every detected rack.

Identify racks first to see available IDs.

Rack IDs are heuristic shape-based detections. Route planning uses 4-connected A* through free map cells to approach each selected rack and return to the dock. The red line is a planned route preview, not physical robot control; verify the map and rack detections before using it on hardware.
